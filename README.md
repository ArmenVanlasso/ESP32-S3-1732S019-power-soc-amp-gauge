# ESP32-S3-1732S019-power-soc-amp-gauge
Na ekran 170x320. Wyświetla takie dane jak SOC, pobór mocy, pobór amper. Zrobiłem go od zera do mojego skutera elektrycznego z 20 akumulatorami LifePo4 40ah i JK BMS.
ESP32 pobiera dane z JK BMS i wyświetla to co wyżej.
Górny łuk zawiera 10 sekcji, które odpowiednio się kolorują
Środkowy pasek i dolny łuk jak wyżej.
Dodatkowo zrobiłem ikony, które pokazują się, gdy bms odetnie zasilanie, gdy minimalne ustawione napięcie na którejś celi spadnie poniżej zadanej wartości, oraz drugą, gdy bms odetnie zasilanie jak pobór mocy będzie większy niż ustalony
